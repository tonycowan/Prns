# What's new

Since the last release.

The app is now called Optio.

A long note is sent in pieces and put back together, so a long message can arrive.

If a note cannot be sent, it is marked Failed. Tap Failed to try again.

A note that arrives twice is kept once.

Under a contact's name, Optio shows how you are connected. A direct connection says direct. A longer path says how many hops it takes. That line stays up to date while the journal is open, and voice and video follow the path you are on.

On Windows, scanning a code opens the camera when the computer has one. If it does not, you can still choose a photo.

On Android, Optio can use a Heltec board plugged into the phone.
